-- alfa e beta são, respectivamente, piso do maximizador e teto do minimizador.

-- Todo o bloco inical de comentários de minimax.txt é válido aqui, além dos valores MATE e INFINITO

-- Na raiz (profundidade == 0), alfa e beta não são atualizados: os filhos da raiz recebem a janela completa e devolvem valores exatos, não limites. Isso é necessário porque listaCandidatos compara valores por igualdade; com a janela apertada, um filho pode devolver um limite igual a melhor e entrar como empate sem ser. Pressupõe chamada inicial com alfa = -INFINITO e beta = +INFINITO. Se a raiz passar a receber janela estreita (ex.: aspiration windows no aprofundamento iterativo), o corte pode ocorrer na raiz e esta garantia deixa de valer.

função podaAlfaBeta(estado, profundidade, alfa, beta):
    se testeEmpateRegra(estado) então
        retorna 0
    senão se profMax <= profundidade então
        retorna avaliar(estado)
    senão 
        listaGerada = gerarLancesLegais(estado)
        se listaGerada == vazio então
            se emXeque(estado) então
                se estado.side_to_move == WHITE então
                    retorna -(MATE - profundidade)
                senão retorna MATE - profundidade
            senão retorna 0
        senão:
            se estado.side_to_move == WHITE faça
                melhor = -INFINITO
                para todo lance em listaGerada faça
                    undo = novo registro
                    make_move(estado, lance, undo)
                    atual = podaAlfaBeta(estado, profundidade + 1, alfa, beta)
                    unmake_move(estado, lance, undo)

                    se atual > melhor então 
                        melhor = atual
                        se melhor > alfa e profundidade > 0 então
                            alfa = melhor
                        se profundidade == 0 então
                            listaCandidatos.limpar()
                            listaCandidatos.adiciona(lance)
                    senão se atual == melhor e profundidade == 0 então:
                        listaCandidatos.adiciona(lance)
                    
                    se alfa >= beta então:
                        interromper
                retornar melhor
            senão:
                melhor = INFINITO
                para todo lance em listaGerada faça
                    undo = novo registro
                    make_move(estado, lance, undo)
                    atual = podaAlfaBeta(estado, profundidade + 1, alfa, beta)
                    unmake_move(estado, lance, undo)

                    se atual < melhor então
                        melhor = atual
                        se melhor < beta e profundidade > 0 então
                            beta = melhor
                        se profundidade == 0 então
                            listaCandidatos.limpar()
                            listaCandidatos.adiciona(lance)
                    senão se atual == melhor e profundidade == 0 então:
                        listaCandidatos.adiciona(lance)
                    
                    se alfa >= beta então:
                        interromper
                retornar melhor
