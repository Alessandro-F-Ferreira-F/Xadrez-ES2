-- testeEmpateRegra(estado) é a função que testa se o estado atual no tabuleiro resulta em um empate  pelas regras, de 50 lances, tripla repetição e material insuficiente

-- gerarLancesLegais(estado) é a função que gera todos os lances válidos, dado um estado

-- emXeque(estado) é a função que testa se o rei do lado da vez está em xeque, dado um estado

-- PROF_MAX é a constante de compilação global que estipula o teto da profundidade pedida a escolherJogada (go depth), dado que a pilha não é infinita (PROF_MAX deve ser maior que 0). Não é a profundidade da busca

-- PROF_LIMITE = 2 * PROF_MAX é o teto absoluto de profundidade de qualquer nó, inclusive além de limiteIteracao (quiescência). Define LIMIAR_MATE: todo mate a até PROF_LIMITE meios-lances é classificado como mate

-- limiteIteracao é a variável global com a profundidade da iteração corrente do aprofundamento iterativo (1, 2, ..., profundidade pedida), definida por escolherJogada antes de cada busca (ver escolherJogada.txt)

-- tempoEsgotado é a variável global (booleana) que indica que o prazo da chamada passou. É desligada em escolherJogada e, depois de ligada, fica ligada até a próxima chamada

-- estourouTempo() liga tempoEsgotado se prazoPassou() (ver escolherJogada.txt) e devolve tempoEsgotado. O relógio só é consultado a cada INTERVALO_RELOGIO nós, e nunca na iteração 1 nem sem limite de tempo (ver escolherJogada.txt)

-- Com tempo esgotado, o nó devolve 0 sem buscar, e o laço devolve 0 logo após desfazer o lance: o valor é descartado pela chamadora, e o estado volta intacto

-- listaCandidatos variável global que guarda a lista de lances possíveis para serem escolhidos, todos empatados no melhor valor, com base nos critérios do minimax. Preenchida apenas na raiz da árvore de busca

-- nosVisitados é a variável global que conta os nós visitados pela busca (NOS_VISITADOS em C): cada entrada em minimax, podaAlfaBeta, quiescenciaMinimax ou quiescenciaAlfaBeta conta um nó, inclusive a raiz, somando todas as iterações. É zerada em escolherJogada. NOS_QUIESCENCIA conta só as entradas nas funções de quiescência (ver quiescencia.txt)

-- quiescenciaAtiva é a variável global (booleana) que liga a quiescência nas folhas: com ela, o nó em limiteIteracao chama a quiescência em vez de avaliar (ver quiescencia.txt). Definida por escolherJogada

-- Valores utilizados como limite para os estados intermediários (ou seja, que não são fim de partida) no retorno de avaliar explicitados em avaliar.txt

-- O valor retornado em um xeque-mate passa a ser (MATE - profundidade), com sinal, sendo negativo se as brancas perdem, positivo se as pretas perdem e a inicialização será feita em + ou - INFINITO. Empate foi convencionado como 0

MATE = 19999
INFINITO = 20000

função minimax(estado, profundidade):
    nosVisitados = nosVisitados + 1
    se estourouTempo() então
        retorna 0

    se testeEmpateRegra(estado) então
        retorna 0
    senão se limiteIteracao <= profundidade então
        se quiescenciaAtiva então
            retorna quiescenciaMinimax(estado, profundidade)
        senão retorna avaliar(estado)
    senão 
        listaGerada = generate_legal_moves(estado)
        se listaGerada == vazio então
            se emXeque(estado) então
                se estado.side_to_move == WHITE então
                    retorna -(MATE - profundidade)
                senão retorna MATE - profundidade
            senão retorna 0
        senão:
            se estado.side_to_move == WHITE faça
                melhor = -INFINITO
                para todo lance em listaGerada faça
                    undo = novo registro
                    make_move(estado, lance, undo)
                    atual = minimax(estado, profundidade + 1)
                    unmake_move(estado, lance, undo)
                    se tempoEsgotado então
                        retorna 0

                    se atual > melhor então 
                        melhor = atual
                        se profundidade == 0 então
                            listaCandidatos.limpar()
                            listaCandidatos.adiciona(lance)
                    senão se atual == melhor e profundidade == 0 então:
                        listaCandidatos.adiciona(lance)
                retornar melhor
            senão:
                melhor = INFINITO
                para todo lance em listaGerada faça
                    undo = novo registro
                    make_move(estado, lance, undo)
                    atual = minimax(estado, profundidade + 1)
                    unmake_move(estado, lance, undo)
                    se tempoEsgotado então
                        retorna 0

                    se atual < melhor então
                        melhor = atual
                        se profundidade == 0 então
                            listaCandidatos.limpar()
                            listaCandidatos.adiciona(lance)
                    senão se atual == melhor e profundidade == 0 então:
                        listaCandidatos.adiciona(lance)
                retornar melhor
